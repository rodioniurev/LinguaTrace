# Сборка

## Что понадобится

- Flutter 3.41 или новее (Dart входит в его состав); проверить окружение можно командой `flutter doctor`.
- Для Windows — Visual Studio 2022 с набором «Разработка классических приложений на C++».
- Для Android — JDK 17 и Android SDK с платформами 34–36 и build-tools 35; NDK Gradle скачает сам при первой сборке.
- Для Linux — пакеты, перечисленные в документации Flutter для сборки под Linux (clang, cmake, ninja, GTK 3).
- Для сборки базы пословиц — Python 3.10 или новее.

Все команды ниже выполняются из папки `flutter_app`, а первой всегда идёт `flutter pub get`.

## Windows

```bash
flutter build windows --release
```

Готовая программа появится в `build/windows/x64/runner/Release/`. На другой компьютер переносится вся эта папка целиком, а не только `lingua_trace.exe`: рядом с ним лежат библиотеки и данные, без которых программа не запустится.

Для работы с Claude по подписке на компьютере должен быть установлен и авторизован Claude Code; программа найдёт его сама или по пути, указанному в настройках.

## Android

```bash
flutter build apk --release --target-platform android-arm64
```

APK появится в `build/app/outputs/flutter-apk/app-release.apk`. Сборка идёт долго, на обычном ноутбуке до двадцати минут, и требует много памяти, поэтому на это время лучше закрыть всё тяжёлое. Релизная сборка подписывается отладочным ключом; чтобы публиковать приложение в магазине, добавьте свою подпись по [инструкции Flutter](https://docs.flutter.dev/deployment/android#sign-the-app).

В `android/gradle.properties` выключена инкрементальная компиляция Kotlin: она ломается, когда проект и кэш пакетов Dart лежат на разных дисках. Если у вас всё на одном диске, её можно включить обратно.

## Linux

```bash
flutter build linux --release
```

## Тесты

```bash
flutter test
```

Тесты не трогают ваши настоящие данные: папку данных они подменяют через переменную окружения `LINGUATRACE_HOME`. Тесты, которые обращаются к настоящим языковым моделям и новостным лентам (`test/live_*_test.dart`), по умолчанию пропускаются; чтобы их запустить, задайте `LT_LIVE=1`.

## Сервер синхронизации

Сервер лежит в папке `server` и собирается отдельно, см. [server/README.md](../server/README.md).

## Где программа хранит данные

На компьютере всё, что накапливается у пользователя (история, записная книжка, ошибки, тренировки, лента, «Идеи» и настройки), лежит в одной папке `Документы\LinguaTrace`; её можно перенести в другое место переменной окружения `LINGUATRACE_HOME`. На Android данные хранятся в личной папке приложения.
