# База пословиц

## Что в ней лежит

База — файл SQLite `flutter_app/assets/proverbs/proverbs.db` с одной таблицей `proverbs`:

| Колонка | Что хранит |
|---|---|
| `text_ru`, `text_es`, `text_en` | пословица на русском, испанском и английском; у части записей есть и `text_de`, `text_fr`, `text_uk`, `text_tr` |
| `literal_en` | подстрочный перевод на английский, чтобы был виден образ |
| `source` | откуда взята запись (см. [DATA_LICENSE.md](../DATA_LICENSE.md)) |
| `confidence` | оценка надёжности источника от 0 до 1 |
| `concept_key` | смысловой ключ ситуации, например `nature-cannot-change` |
| `region` | регион для испанских региональных пословиц (`canarias`, `aragon` и т. д.) |

Сейчас записей в открытой базе 9 371: с русским текстом — 419, с испанским — 8 465, с английским — 1 302; пар «русский — испанский» среди них 149, а записей со смысловым ключом 204.

## Главное правило

Пустое поле лучше ложной пары. Пользователь, который видит «эквивалента нет», ищет дальше, а тот, кто видит уверенный неправильный эквивалент, запоминает его. Поэтому эквивалент записывается в базу, только если он засвидетельствован в словаре, сборнике или другом источнике, который можно назвать; машинный перевод пословицы эквивалентом не считается.

## Размеченное ядро и смысловые ключи

Самая ценная часть базы — размеченное ядро в `flutter_app/tool/data/curated_core.json`: пары, сверенные по словарям, с типом эквивалентности и смысловыми ключами. Запись выглядит так:

```json
{
  "id": "ru-001",
  "text_ru": "Не всё то золото, что блестит",
  "text_es": "No es oro todo lo que reluce",
  "text_en": "All that glitters is not gold",
  "literal_en": "Not all that glitters is gold",
  "concept_key": "appearance-deceives",
  "region": "",
  "equivalence": "full",
  "confidence": 0.98,
  "notes": "Классическая словарная пара во всех трёх языках"
}
```

- `equivalence` — тип связи: `full` (тот же образ и смысл), `analog` (смысл тот же, образ другой) или `single` (пословица на одном языке, засвидетельствованного эквивалента нет, и пара не ставится).
- `concept_key` описывает ситуацию, а не слова: короткая английская метка через дефис. Под одним ключом должны лежать пословицы, которые говорят в одних и тех же обстоятельствах, даже если у них нет ни одного общего слова. Прежде чем заводить новый ключ, посмотрите, нет ли подходящего среди существующих.
- `region` заполняется для испанских региональных пословиц: `canarias`, `andalucia`, `aragon`, `asturias`, `castilla` и т. д.
- В `notes` указывается, откуда взята пара и чем она примечательна.

Сейчас у записи может быть только один ключ. Пословицы, которые подходят под несколько ситуаций, лучше всего было бы описывать несколькими ключами с оценкой уверенности, и это одна из открытых задач проекта.

## Как пересобрать базу

Новые записи ядра попадают в базу после пересборки (из папки `flutter_app`):

```bash
python tool/rebuild_db_v4.py --public
```

Скрипт берёт из текущей базы все записи, кроме словаря Киселёва и прежнего ядра, заново добавляет ядро из JSON, убирает дубли и пишет базу обратно в `assets/proverbs/proverbs.db`. Флаг `--public` оставляет только записи, которые можно распространять; без него скрипт попробует найти PDF словаря Киселёва и добавить его пары, что годится только для личной сборки. Дополнительные записи можно подмешать из JSON-файла параметром `--extra-json путь`.

Скрипт `tool/build_proverbs_db.py` собирает базу с нуля из открытых источников: страниц пословиц английского Викицитатника и Википедии, а при желании ещё «Многоязычного рефранеро», LIdioms и словаря Киселёва. Учтите, что он перезапишет файл базы и не восстановит записи испанского Викицитатника, импортированные раньше отдельно, поэтому для пополнения базы удобнее `rebuild_db_v4.py`. Для базы, которую можно распространять, запускайте его с ключами `--skip-refranero --skip-lidioms --skip-kiselev`.

## Как проверить результат

После пересборки запустите тесты поиска пословиц (`flutter test test/proverb_service_test.dart`) и проверьте вручную несколько запросов: пословицу с ударениями и без них, пословицу внутри фразы и пару с разными образами под одним ключом.
